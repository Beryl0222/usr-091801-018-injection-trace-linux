# 医美注射全程追溯

本项目记录注射类医疗美容服务的机构资质、人员资质、材料批次、治疗确认和术后随访。水光注射是一种操作方式，不代表固定产品；每项成分必须单独登记批准文号、储运记录、启封时间和实际用量。

随访窗口区分短期反应、感染风险与迟发异常，只生成复诊提醒，不给出自动诊断。生活美容机构不属于合法注射地点。样例材料包括透明质酸、肉毒素以及应被阻断的来源不明粉剂。

## 模块

- `service.py`：基础健康检查入口。
- `domain.py`：领域模型与七条硬性规则；治疗先完成全部校验再扣减库存，被阻断时不留半扣减状态；随访只产生分级复诊提醒。
- `sample_data.py`：上线前验收样例（连锁两门店与生活美容馆、有效/过期资质、透明质酸/肉毒素/胶原蛋白/来源不明粉剂、带温控记录的批次）。
- `service_contract.py` / `domain_test.py` / `acceptance_test.py`：基础契约、规则单测、跨门店复诊追查验收。

## 硬性规则（写入每次治疗记录）

- **R1 机构诊疗科目**：须持医疗机构执业许可并登记美容皮肤科，生活美容机构一律阻断。
- **R2 人员资质有效期**：主诊医生与护士的执业资质须在治疗当日有效。
- **R3 材料批准文号**：每项成分单独登记批准文号，来源不明直接阻断。
- **R4 机构组合规则**：同次材料种数、禁用成分组合、单材料用量不得超机构规则。
- **R5 批次状态**：批次未召回、未过期；已启封支剂不得跨治疗复用，重复扫描只扣减一次库存。
- **R6 逐项成分确认**：顾客须逐项确认成分，"水光+"套餐确认不能代替逐项确认。
- **R7 皮肤状态与适应性判断**：医生必须基于皮肤状态记录适应性判断。

## 数据边界

召回批次、资质失效、顾客撤回营销授权只影响各自合法范围：阻断后续行为，历史医疗记录按规定留存。跨门店复诊时，接诊者仅可见过敏史、既往材料批次与症状报告等必要病史，联系方式与营销授权不外泄。

## 运行

- `python3 service.py --check` 检查基础信息，`python3 service.py --port 8000` 提供健康检查。
- `npm test` 或 `python3 -m unittest -v service_contract domain_test acceptance_test` 运行全部测试。
