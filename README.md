# 医美注射全程追溯

记录注射类医疗美容服务的机构资质、人员资质、材料批次、治疗确认和术后随访，
支撑连锁机构对“注射数日或数月后出现硬结”类复诊的跨门店追查。

“水光”是一种操作方式，不代表固定产品。**每项成分必须单独登记批准文号、
储运记录、启封时间、实际用量与余量去向**；顾客逐项确认成分，而不是只确认
“水光+”套餐。随访只生成复诊提醒，**不自动下诊断**。

## 运行

```bash
python3 service.py --check       # 基础自检
python3 service.py --scenario    # 跨门店复诊追查验收（49 项硬断言）
npm test                         # 契约测试 + 31 项领域单测 + 验收场景
python3 service.py --port 8000   # 健康检查
```

## 治疗全流程与硬性阻断

规则册版本 `RB-2026.1`，归档时对全部规则评估并将结果（含通过项）写入病历：

| 编号 | 规则 | 编号 | 规则 |
|---|---|---|---|
| R101 | 必须是合法医疗机构（生活美容馆禁止注射） | R501 | 实物支料在库归属、不得跨店领用 |
| R102 | 必须登记医疗美容科诊疗科目 | R502 | 一启一患：启封绑定当次治疗，禁止复用 |
| R201 | 医师资质有效期/执业范围/门店备案 | R503 | 启封后 4 小时使用时限 |
| R211 | 护士资质（独立核验，互不吞并） | R504 | 用量+余量平账、余量须记录医疗废物处置 |
| R301 | 医师本人基于皮肤状态记录适应性判断 | R505 | 核销幂等：一支全局只扣减一次 |
| R302 | 判定不适应即阻断 | R601 | 单次治疗成分组合上限 2 种 |
| R401 | 批准文号在册、来源不明硬性阻断 | R602 | 单成分单次最大剂量 |
| R402–R406 | 批次归属/效期/全程温控/检疫冻结/召回 | R701/R702 | 逐项成分知情同意、记账不得为空 |

流程顺序：治疗前核验 → 开立治疗 → 医师皮肤评估 → 顾客逐项确认（成分+文号+
批号+支料条码）→ 扫描启封（重复扫描幂等零扣减）→ 登记用量与余量 →
`finalize` 全量规则评估 → 通过后**原子**核销并冻结病历；不通过则库存零扣减、
已启封支料按医疗废物弃置。

## 术后随访（规则 `FU-2026.1`，只提醒不诊断）

| 窗口 | 时间 | 典型信号与分级 |
|---|---|---|
| EARLY 短期反应 | 0–7 天 | 轻度红肿 L1；红肿热痛加重 L2（24h 复诊） |
| INFECTION 感染风险 | 8–30 天 | 针眼渗液化脓 L2；视力变化/眼周剧痛/高热扩散 L3（立即急诊） |
| LATE 迟发异常 | 31–180 天 | 肤色持续异常 L2 |
| DELAYED 迟发结节 | 180 天以上 | 新发硬结/结节 L2（3 日内复诊，提示迟发结节信号） |

## 合法范围隔离

- **批次召回**：只阻断该批次新治疗，不删除、不改写旧病历，不波及其余批次。
- **资质失效**：立即阻断新开治疗与病史调阅；既往病历按签署时事实原样留存。
- **营销授权撤回**：只移出营销名单；医疗服务与病历不受影响。
- **病历留存**：归档即不可变快照，自治疗日起留存 15 年，列清规则册版本、
  全部 21 条规则评估结果与全部批次（产品/文号/批号/支料/用量/余量去向）。

## 跨门店复诊的最小必要病史

接诊医师须本人资质有效且在接诊门店备案；只能调阅与主诉部位相关、365 天内的
病史，视图不含证件号、护士信息、温控流水与营销状态；每次调阅留痕，
越权调阅被拒且不返回数据。

## 代码结构

```
traceability/
  clock.py       可注入时钟（随访窗口判断可复现）
  models.py      门店/人员/产品/批次/支料/治疗/随访模型
  rules.py       版本化放行规则册（任何阻断带规则编号）
  inventory.py   批次库存、支料扫描启封、原子核销（幂等）
  app.py         应用服务：核验→评估→确认→记账→归档→随访→召回→授权
  records.py     不可变病历快照（规则结果 + 全部批次 + 15 年留存）
  follow_up.py   风险时间窗与症状分级（L1/L2/L3，不诊断）
  history.py     跨门店最小必要病史视图与访问留痕
  seed.py        验收样例数据
  scenario.py    跨门店复诊追查验收场景（49 项断言）
  test_traceability.py  31 项领域单元测试
```
